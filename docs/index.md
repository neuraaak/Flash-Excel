**Flash-Excel** is a Windows desktop application that cleans and reshapes Excel and CSV files with reusable presets: you describe the transformation once, then apply it to any number of files, by hand or on a schedule.

## 🚀 Quick start

New to Flash-Excel? [Get started](get-started.md) takes you from the installer to your first transformed file in a few minutes.
