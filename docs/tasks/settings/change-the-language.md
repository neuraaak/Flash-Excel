# Change the language

Switch the Flash-Excel interface between English and French.

## 🔧 Prerequisites

- None.

## 📝 Steps

1. In the sidebar, select **Settings**.
2. Under **Language**, select **English** or **French**.
3. Close the **Settings** window.

## ✅ Result

The interface switches to the chosen language at once, and Flash-Excel keeps it the next time it starts.

!!! note "Language chosen in the installer"
    When you install Flash-Excel, the language picked in the installer becomes the interface language. A later choice in **Settings** wins, until you reinstall.

!!! note "What the language also changes"
    The language also sets how true/false (Boolean) values are written in Excel output: `True` / `False` in English, `VRAI` / `FAUX` in French. The names of the computed-column functions, such as `CONCATENER`, stay in French in both languages.
