# Change the theme

Change the colors of the Flash-Excel window: pick a color palette and a dark or light mode.

## 🔧 Prerequisites

- None.

## 📝 Steps

1. In the sidebar, select **Settings**.
2. Under **Appearance** › **Color palette**, select a palette: **Blue Gray**, **GitHub** or **Warm Dark**.
3. Under **Mode**, select **Dark** or **Light**.
4. Close the **Settings** window with **×**, ++esc++, or by clicking outside it.

## ✅ Result

The window takes the new colors as soon as you select them, and Flash-Excel keeps them the next time it starts. By default, Flash-Excel uses the **Blue Gray** palette in **Dark** mode.
