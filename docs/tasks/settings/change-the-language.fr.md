# Changer la langue

Basculez l'interface de Flash-Excel entre l'anglais et le français.

## 🔧 Prérequis

- Aucun.

## 📝 Étapes

1. Dans la barre latérale, sélectionnez **Paramètres**.
2. Sous **Langue**, sélectionnez **Anglais** ou **Français**.
3. Fermez la fenêtre **Paramètres**.

## ✅ Résultat

L'interface passe aussitôt dans la langue choisie, et Flash-Excel la conserve au prochain démarrage.

!!! note "Langue choisie dans l'installateur"
    À l'installation de Flash-Excel, la langue choisie dans l'installateur devient la langue de l'interface. Un choix ultérieur dans **Paramètres** l'emporte, jusqu'à une réinstallation.

!!! note "Ce que la langue change aussi"
    La langue détermine aussi l'écriture des valeurs vrai/faux (booléennes) dans les fichiers Excel produits : `True` / `False` en anglais, `VRAI` / `FAUX` en français. Les noms des fonctions de colonnes calculées, comme `CONCATENER`, restent en français dans les deux langues.
