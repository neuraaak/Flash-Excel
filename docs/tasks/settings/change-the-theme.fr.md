# Changer le thème

Changez les couleurs de la fenêtre de Flash-Excel : choisissez une palette de couleurs et un mode sombre ou clair.

## 🔧 Prérequis

- Aucun.

## 📝 Étapes

1. Dans la barre latérale, sélectionnez **Paramètres**.
2. Sous **Apparence** › **Palette de couleurs**, sélectionnez une palette : **Blue Gray**, **GitHub** ou **Warm Dark**.
3. Sous **Mode**, sélectionnez **Sombre** ou **Clair**.
4. Fermez la fenêtre **Paramètres** avec **×**, ++esc++ ou en cliquant à l'extérieur.

## ✅ Résultat

La fenêtre prend les nouvelles couleurs dès que vous les sélectionnez, et Flash-Excel les conserve au prochain démarrage. Par défaut, Flash-Excel utilise la palette **Blue Gray** en mode **Sombre**.
