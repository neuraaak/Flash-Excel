# Exporter un préréglage

Enregistrez une copie d'un fichier de préréglage à l'endroit de votre choix, pour le sauvegarder, l'envoyer à un collègue ou le placer dans un dossier partagé.

## 🔧 Prérequis

- Un préréglage enregistré qui vous appartient, listé avec le libellé **Local**. Les préréglages d'un dossier partagé ne peuvent pas être exportés.

## 📝 Étapes

1. Dans la barre latérale, sélectionnez **Préréglages**.
2. Sélectionnez le préréglage dans la liste à gauche.
3. Dans la barre d'outils, sélectionnez **Exporter**.
4. Dans la boîte de dialogue d'enregistrement, choisissez un dossier. Le fichier garde le nom du fichier de préréglage, par exemple `monthly_report.toml` ; modifiez-le si besoin.
5. Validez l'enregistrement dans la boîte de dialogue.

## ✅ Résultat

Le message **Préréglage exporté** apparaît et une copie du fichier `.toml` se trouve dans le dossier choisi. Le préréglage dans Flash-Excel est inchangé.

Pour utiliser la copie sur un autre ordinateur, placez-la dans le dossier `Documents\flash-excel\presets` de cet ordinateur, ou dans un dossier ajouté comme source partagée.
