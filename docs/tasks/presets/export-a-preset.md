# Export a preset

Save a copy of a preset file anywhere you choose, to back it up, send it to a colleague or place it in a shared folder.

## 🔧 Prerequisites

- A saved preset of your own, listed with the label **Local**. Presets from a shared folder cannot be exported.

## 📝 Steps

1. In the sidebar, select **Presets**.
2. Select the preset in the list on the left.
3. In the toolbar, select **Export**.
4. In the save dialog, choose a folder. The file keeps the name of the preset file, for example `monthly_report.toml`; change it if needed.
5. Select **Save** in the dialog.

## ✅ Result

The message **Preset exported** appears and a copy of the `.toml` file is in the folder you chose. The preset in Flash-Excel is unchanged.

To use the copy on another computer, put it in the `Documents\flash-excel\presets` folder of that computer, or in a folder added as a shared source.
