# Disable or delete a scheduled task

Stop a preset that Flash-Excel scheduled from running every day, for a while or for good.

## 🔧 Prerequisites

- A task created with **Add to Task Scheduler**. See [Schedule a preset](schedule-a-preset.md).

## 📝 Steps

1. Open the Windows Start menu, search for **Task Scheduler** and open it.
2. In the left pane, expand **Task Scheduler Library** and open the **Flash-Excel** folder.
3. Right-click the task, then:
    - choose **Disable** to pause future runs, or
    - choose **Delete** and confirm to remove the task.

## ✅ Result

A disabled task stays in the list with the status **Disabled** and does not run until you choose **Enable**. A deleted task is gone from the list.

Disabling or deleting a task does not delete your preset, your source files or the files already produced.
